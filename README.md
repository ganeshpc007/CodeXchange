# Chatify - Simplifying Private Chats (Still In Development)

Chatify is a user-friendly web app designed for private messaging. With Chatify, individuals can seamlessly engage in private conversations with ease.

## Purpose

The main objective behind Chatify is to master core concepts such as database management, RESTful APIs, and component building within web development. By focusing on these fundamentals, we aim to create a reliable and efficient chat application.

## Tech Stack

- Database: MongoDB
- Backend: Express API's
- Frontend: Modern React
- Frontend Components: Material UI
- Web Socket: socket.io

## Getting Started

1. Navigate to the `client` directory.
2. Run `npm run dev` to start the development server.
